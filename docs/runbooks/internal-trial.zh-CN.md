# AlignSpace 内部模拟试用手册（中文）

> **重要：这是内部模拟试用，不是真实用户研究。** 执行者自行使用两个模拟账户走查产品，
> 不能写成“用户认可”“满意度达标”。**图片分析仍是确定性模拟**（每张图四条固定观察），
> 因此不能用本试用评价真实识图准确率，也不能暗示模型理解了图片内容。

## 1. 角色与账户

- **屋主账户**：创建项目、上传参考图片、回答访谈问题、确认偏好、处理冲突、批准方案。
- **设计师账户**：通过一次性项目码加入、录入/修改/撤销约束、反馈、批准同一方案。
- 两个账户必须是不同邮箱；建议使用两个独立浏览器 profile 或两个 Chromium context，避免共用 Cookie。

## 2. 环境准备

- Python 3.12 与 `uv`；Node.js 20.19+/22.12+（Vite 7）。
- 端口：后端 `127.0.0.1:8000`，前端 `127.0.0.1:5173`。端口被占用时先停止对应进程，不要改用会与 Cookie/Origin 配置冲突的地址。
- 默认使用以下三个数据路径（可用环境变量覆盖）：

```text
ALIGNSPACE_DATABASE_URL=sqlite:///alignspace-accounts.db
ALIGNSPACE_CHECKPOINT_PATH=alignspace-accounts-checkpoints.db
ALIGNSPACE_ASSET_DIR=var/assets
```

## 3. 启动

```bash
# 后端（仓库根目录）
export ALIGNSPACE_AUTH_SECRET="$(openssl rand -hex 32)"   # 不打印、不硬编码、不提交
export ALIGNSPACE_DEV=1
export ALIGNSPACE_ORIGINS="http://localhost:5173,http://127.0.0.1:5173"
uv run uvicorn alignspace.main:app --host 127.0.0.1 --port 8000

# 前端（另开终端）
cd frontend && npm ci && npm run dev
```

打开 `http://127.0.0.1:5173`。缺少密钥或密钥不足 32 字节时后端拒绝启动；换密钥会使旧访问令牌失效。

## 4. 三个试用案例

### 案例一：普通对齐并生成方案

1. 屋主注册并登录，创建客厅项目，勾选“同意处理参考图片（真实上传，模拟分析）”。
2. 上传 3 张图片（演示样本卡；**图片是真实的，分析是模拟的**）。生成项目码。
3. 设计师用另一账户注册、登录，输入项目码加入。
4. 屋主点击“启动分析”，界面出现“广泛偏好问题”。
5. 屋主勾选希望保留的**部位**（这些部位来自固定的模拟观察），提交；随后逐个细化问题选择“喜欢”，或对不重要的项选择“不在意”，也可“跳过”。
6. 屋主用“显式偏好”补充风格/布局/家具/氛围/功能等，点击“保存偏好”。
7. 设计师录入约束并“提交设计师反馈”，生成“方案版本 v1”。
8. 屋主与设计师分别点击“批准此版本”，项目变为“已批准”。

**预期**：偏好可追溯到来源图片、部位与维度；方案包含最新约束；双方对同一版本与内容哈希批准。

### 案例二：冲突后修改并重新审批

1. 承接案例一（生成方案前），设计师录入一条约束，声明**不兼容取值**并关联到已确认偏好，勾选后保存。
2. 屋主在“当前任务”回答冲突问题；方案随之生成。
3. 设计师修改约束（或新增约束）→ 方案被标记“已过时”，旧审批清空。
4. 屋主点击“重新生成方案”得到新版本，双方重新批准同一新版本。

**预期**：未解决冲突不会被自动标记为已解决；过时方案不能审批；重新生成保留用户已编辑的方案目标。

### 案例三：跳过、删除来源图、服务中断与重试、备份恢复

1. 屋主“跳过”当前问题：不创建任何偏好，流程继续到下一题。
2. 屋主删除当前问题唯一来源图片：该问题退役，其他图片的可问部位继续被提问；已确认偏好保留并标注“来源图片已删除”。
3. 模拟服务中断：停止后端进程后重新启动（同一数据路径与密钥），重新登录；待办问题与方案历史仍在，可继续提交，不产生重复问题或重复版本。
4. 备份与恢复：停止服务，按 [本地离线备份与恢复手册](local-backup-restore.zh-CN.md) 备份并恢复到新目录，用恢复后的三个路径启动，重新登录并继续（例如继续审批）。

**预期**：跳过不建空记录；删除退役问题且不卡住流程；重启后状态一致；恢复后可继续工作。

## 5. 错误处理速查

| 现象 | 处理 |
|---|---|
| 401 / 会话失效 | 重新登录；确认后端密钥未更换 |
| 409 / 版本冲突 | 输入会保留，页面刷新后由用户**明确**重新提交（使用新幂等键）；不要静默覆盖 |
| 网络失败 | 写入会以同键同体重试一次；仍失败时提示可重试，不无限请求 |
| 图片缺失 / 来源已删除 | 已确认偏好保留并标注来源删除；未确认观察会随来源删除退役 |
| 无待办 | 若等待另一方，页面会提示；若确无任务，检查是否已达问题上限 |
| 备份校验失败 | 不要恢复；按备份手册换用其它备份 |

需要后端日志与 `correlationId` 才能定位的：认证失败、数据库错误、未预期的 5xx。用户可自行恢复的：401 重新登录、409 刷新后重新提交、网络失败重试。

## 6. 结束

正常点击“退出登录”，停止两个服务。演示重置请**切换到一组全新数据路径**（见备份手册第 6 节），不要清空正在使用的目录。

## 7. 明确不在范围内

真实图片识别/多模态、自由文本理解、自动估价、平面图/空间建模/三维编辑/效果图生成、邮箱验证与密码找回、云部署、说明书导出与历史版本 UI。
