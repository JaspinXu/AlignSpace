# 分轮访谈与中英界面

访谈先补齐八个核心维度，再用 55 个可选细节问题逐步澄清。问题库位于 `app/interview.py`，按核心答案与前序细节触发。例如选择木材后才问木纹，选择明显木纹后再问纹理走向；选择曲线家具后才询问曲线出现的位置。排序优先补齐核心词汇，再考虑条件追问和分歧，属于启发式排序，不是经过统计校准的信息增益。

每个项目的共享访谈计数到十题便停下，需要参与者明确选择继续，才开放下一轮十题。两种角色仍只回答各自问题。任意时刻可以暂停；暂停只影响当前角色，恢复后保持当前进度。核心决定和实际约束决定简报是否能审批，可选细节不要求全部答完。

细节答案单独记录在 `designDetails`，包含回答人、时间、问题、选择、当时的核心依据和重新审阅标记。改变核心选择或相关前序答案后，受影响的细节显示需要核对；在共享简报的「修改决定」中可以修改已回答的细节，或移除它。新回答和内容修改清除审批；单纯暂停或继续不会改变内容哈希、简报版本或现有审批。接口继承角色权限、状态版本校验和审计记录。

## 中英文

页头语言按钮在桌面与手机上均可见，选择保存在浏览器。界面、表单提示、问题、选项、参考释义、动态状态和房型标签使用本地词表，切换不重新生成项目、不提交表单、不改写用户笔记或项目名称。房型保留稳定的值，显示标签随语言改变。

- `app/static/locale-zh.txt`：界面词条。
- `app/interview.py`：细节问题与选项的中英文。
- `scripts/build_locale.py`：参考资料的中文释义及编译脚本。执行 `python scripts/build_locale.py` 更新 `locale-data.js`。原文段落 ID 改变时脚本会停止，要求先审阅对应释义。
- `app/static/i18n.js`：本地界面翻译与原文恢复。无需外部翻译服务，不传送用户表单内容。
- `app/language.py`：常见中英文设计检索词映射。无法识别的文字保留给来源搜索。

手册链接已从设计参考卡片移除。定义和摘录默认展开，并使用独立背景突出；中文模式显示明确标注的编辑释义，英文模式保留原文。源地址、版本与引用仍保存在导出的证据快照中。Qanvast 案例原始链接及 Getty 术语链接保留。

配置模型时，笔记提示要求理解中文、英文、混合表达及否定词，证据描述跟随笔记语言。本地备用分析也识别常见中英文关键词与否定表达，但不声称理解任意自然语言或分析图片像素。用户仍需逐项确认建议。
