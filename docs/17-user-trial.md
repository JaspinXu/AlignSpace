# First user trial — owner-operated, not external research

The team currently has no licensed room-image dataset or recruited designer participant. The project owner will operate the trial. Record this as an owner usability test; do not count role switching as two independent users or claim SME validation.

## Tasks

1. Without reading the README, create a living-room project. Explain what you think the app will produce.
2. Add the note: “I like light oak and warm colours, but not marble.” Run suggestions. Confirm an element and reject another. Did the interface make the difference between a suggestion and a confirmed preference clear?
3. Answer the homeowner questions. Record any term you do not understand.
4. Open a designer invitation in a private window. Answer the layout and care questions. Add a constraint incompatible with one confirmed preference.
5. Resolve the constraint from the designer session. Revise the homeowner preference if necessary. Refresh the other session.
6. Approve from both sessions and export. Change one decision and check that approvals are removed.
