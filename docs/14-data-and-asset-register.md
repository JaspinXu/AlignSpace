## Required before use

Stable ID; description; source/creator; rights basis; consent/license evidence; allowed modification, model input, demo and redistribution; attribution; retention/deletion; accountable owner.

## AI-generated visuals

Record provider/model, date, prompt owner, source references and rights, material edits, intended use, and required disclosure. Review for confusing similarity, marks/text, personal likeness, unsafe content, and provider terms.

## Upload provenance values

`created_by_user`, `licensed_by_user`, `permission_obtained`, `reference_only_unknown_rights`, `team_demo_asset`.

Unknown-rights images must not enter a reusable catalogue or public submission bundle.
